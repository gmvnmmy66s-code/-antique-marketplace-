# سوق الكويت القديم | Old Kuwait Market

موقع سوق إلكتروني كامل لبيع وشراء المقتنيات والتحف الكويتية التراثية، مبني بالكامل بـ **HTML و CSS و JavaScript فقط** (بدون أي إطار عمل مثل Bootstrap أو React).

## طريقة التشغيل محليًا

لا يحتاج المشروع لأي تثبيت أو خادم — فقط افتح `index.html` مباشرة في أي متصفح، أو استخدم خادمًا محليًا بسيطًا (مثل امتداد Live Server في VS Code) لتجربة أفضل.

## النشر على Netlify

المشروع جاهز للنشر مباشرة على Netlify بأي من الطريقتين التاليتين:

**الطريقة الأولى — السحب والإفلات (الأسرع):**
1. افتح [app.netlify.com/drop](https://app.netlify.com/drop)
2. فك ضغط ملف الـ ZIP، ثم اسحب المجلد الناتج (الذي يحتوي على `index.html` مباشرة) إلى الصفحة
3. سيُنشر الموقع فورًا برابط Netlify مجاني (يمكن تخصيصه لاحقًا)

**الطريقة الثانية — عبر Git (لتحديثات مستمرة):**
1. ارفع محتويات المشروع إلى مستودع GitHub/GitLab
2. من لوحة Netlify: `Add new site` → `Import an existing project` → اختر المستودع
3. اترك حقل Build command فارغًا، واجعل Publish directory = `.` (كما هو محدد في `netlify.toml`)
4. اضغط Deploy

المشروع يتضمن ملفي إعداد جاهزين لـ Netlify:
- `netlify.toml` — إعدادات النشر وسياسات التخزين المؤقت (Cache) للملفات الثابتة
- `_redirects` — يوجّه أي رابط غير موجود تلقائيًا إلى صفحة `404.html` المخصصة

## الميزات المطبقة

- بحث فوري في الهيدر + صفحة بحث مستقلة
- فلترة حسب القسم، السعر، التقييم، ونوع البيع (مزاد/مباشر)
- سلة تسوق ومفضلة محفوظتان في `localStorage`
- صفحة تفاصيل منتج مع معرض صور (Lightbox)، تبويبات، تقييمات، ومنتجات مشابهة
- نظام مزاد تجريبي بعدّاد تنازلي ومزايدة
- واجهة دردشة بين بائع ومشتري (تفاعلية بالكامل، بدون اتصال خلفي فعلي)
- نموذج إضافة إعلان مع رفع صور بالسحب والإفلات (Drag & Drop) ومعاينة فورية
- الوضع الليلي/النهاري وتبديل اللغة (عربي/إنجليزي مع دعم RTL/LTR) — محفوظان بين الزيارات
- تحميل كسول للصور (`loading="lazy"`) وحركات ظهور عند التمرير (Scroll Reveal)
- إشعارات Toast لكل عملية (إضافة للسلة، تسجيل دخول، إلخ)
- تصميم متجاوب بالكامل (جوال / آيباد / كمبيوتر)
- وسوم SEO أساسية (title, description, keywords, Open Graph) في كل صفحة

## ملاحظة مهمة حول الصور

نظرًا لعدم امتلاكي القدرة على التقاط أو جلب صور تصوير فعلية موثقة لكل قطعة تراثية، تم استخدام **صور بديلة مصممة بألوان هوية الموقع (ذهبي/بني/بيج) ومكتوب عليها اسم كل منتج بالعربية**، بدلاً من صور عشوائية غير ذات صلة. هذا يضمن أن كل منتج له صورة متسقة ومربوطة باسمه دون كسر أي رابط.

**قبل النشر الفعلي، يُنصح بشدة باستبدال هذه الصور بصور تصوير حقيقية لكل قطعة** — ببساطة استبدل قيم `images` و`image` الخاصة بكل منتج داخل `assets/js/products-data.js` بروابط صورك الحقيقية (محلية أو مستضافة).

## نظام تسجيل الدخول

نظام تسجيل الدخول والتسجيل في هذا المشروع **محاكاة (Frontend فقط)** بدون قاعدة بيانات أو خادم فعلي — يتم حفظ بيانات المستخدم في `localStorage` فقط. لربط الموقع بنظام حقيقي، ستحتاج إلى بناء خلفية (Backend) بلغة مثل Node.js أو PHP مع قاعدة بيانات، واستبدال دوال `initAuthForms()` في `script.js` بطلبات API فعلية.

## التخصيص

جميع الألوان معرّفة كمتغيرات CSS في أعلى ملف `assets/css/style.css` ضمن `:root` — يمكنك تغيير الهوية اللونية للموقع بالكامل من مكان واحد فقط.
